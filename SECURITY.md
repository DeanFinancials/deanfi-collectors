# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, where it is (file, workflow, or output), and the steps needed to reproduce it. We will acknowledge the report, investigate, and coordinate a fix and any disclosure with you.

## Scope

This policy covers the code and GitHub Actions workflows in this repository. Rules for handling secrets and workflow permissions are in [docs/requirements.md](docs/requirements.md) and [docs/workflows.md](docs/workflows.md).
